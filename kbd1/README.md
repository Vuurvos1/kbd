# KBD1

A Corne / Lily58 inspired 56-key split wireless keyboard, designed with [Ergogen](https://docs.ergogen.xyz/) and [KiCad](https://www.kicad.org/).

## BOM (Bill of Materials)

For a full build you need:


| Qty | Component               | Notes                                                      |
| --- | ----------------------- | ---------------------------------------------------------- |
| 56x | KS-33 hotswap sockets   | or MX hotswap sockets                                      |
| 56x | KS-33 switches          | or MX style switches                                       |
| 56x | SOD-123 diodes          |                                                            |
| 2x  | Panasonic EVQPUC        | reset button                                               |
| 2x  | PCM12SMTR               | power switch (or Alps SSSS811101 / G-Switch MK-12C02-G015) |
| 2x  | JST PH 2-pin (2.0mm)    | for battery connection                                     |
| 2x  | 3.7V 750mAh LiPo       | ~35x50x3.5mm                                               |
| 2x  | nice!nano v2            | or compatible nRF52840 board                               |
| 4x  | Mill-Max 1x12 sockets   | for socketing the MCUs                                     |
| —   | MCU pins                | diode legs work well                                       |
| 4x  | M2.5x3x3.5 heatset inserts | for case assembly                                      |
| 6x  | M2.5x4x3.5 heatset inserts | for case assembly                                      |
| 4x  | M2.5x6 countersunk screws  | for case assembly                                      |
| 6x  | M2.5x8 countersunk screws  | for case assembly                                      |
| 8x  | Rubber feet             | 10mm circle                                                |
| 1x  | Keycap set              | LSA or similar                                             |
| 2x  | nice!view display       | optional                                                   |
